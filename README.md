
# LangSpace

Desktop-приложение для изучения иностранных языков с использованием системы уровней владения языком от A1 до C2.

Проект разработан в рамках курсовой работы и включает проектирование реляционной базы данных, реализацию пользовательского интерфейса и бизнес-логики приложения.

## Функциональность

- Работа с иностранными языками и уровнями владения
- Изучение лексики с помощью карточек
- Изучение грамматических правил
- Прохождение тестов
- Сохранение результатов тестирования
- Создание пользовательских заметок
- Работа с учебными материалами
- Управление целями обучения

## Технологии

- C#
- .NET
- WPF
- XAML
- MVVM
- Entity Framework Core
- PostgreSQL

## Архитектура

| Компонент | Назначение |
|---|---|
| Models | Модели данных и контекст базы данных |
| ViewModel | Логика взаимодействия с интерфейсом |
| Views | Пользовательский интерфейс |
| Service | Прикладная логика |
| Images, Fonts | Ресурсы приложения |

## База данных

Реляционная база данных хранит информацию о пользователях, языках, уровнях, учебных материалах, тестах и результатах обучения.

Для взаимодействия приложения с базой данных используется Entity Framework Core.

## Запуск

1. Клонировать репозиторий.
2. Открыть LangSpace.sln в Visual Studio.
3. Восстановить зависимости NuGet.
4. Подготовить базу данных PostgreSQL и настроить подключение.
5. Собрать и запустить приложение.

## Цель проекта

Разработка приложения с полным циклом проектирования базы данных, реализацией бизнес-логики и пользовательского интерфейса.
